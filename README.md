# 잼스의 역사 땅따먹기

[온라인 게임 바로 시작](https://jams-history-territory.sunlitbrush7.chatgpt.site)

문제를 만들고 풀며 한반도 지도에서 영토를 넓히는 온라인 한국사 학습 게임입니다.

## 참여 방법

1. 교사는 온라인 게임에서 **교사로 시작 → 새 게임방 만들기**를 누릅니다.
2. **학생 링크 · QR** 버튼으로 학생 참여 링크를 복사하거나 QR을 보여 줍니다.
3. 학생은 링크 또는 QR로 접속해 **나라와 자기 이름**을 입력합니다. 방 코드는 자동 입력됩니다.
4. 일반 접속 주소를 열었을 때는 교사가 알려 준 6자리 방 코드를 입력합니다.

별도 계정이나 비밀번호는 필요하지 않습니다. 교사방 관리 권한은 해당 브라우저에 저장되므로 교사 브라우저의 저장 데이터를 지우지 마세요.

## 주요 기능

- 한반도와 고구려 북방 학습 영역을 포함한 확장 지도
- 기본 문제 영토 200칸 + 미개척지 300칸 + 울릉도·독도 2칸 (새 방 502칸)
- 고구려 초록·백제 빨강·신라 노랑·가야 보라
- 시작 위치: 국내성(지안), 한성(서울), 금성(경주), 금관가야(김해) 근처
- 일반 영토 1점, 파란 ×2 표시 한강 유역 2점 (현재 소유 나라에 반영)
- 미개척지 선택 → 문제 등록 → 교사 승인 후 해당 칸 개척·점령
- 시대순 역사 여정
- 기본 한국사 객관식 200문항 및 해설
- 시대·나라·인물·유물·유적·사건 등 분류와 학생 문제 출제
- 교사 승인 후 문제은행 저장 및 미개척지 점령
- 정답 풀이, 재점령, 나라별 점령 현황
- 서버 저장, 교사의 일시정지·지도 색상 변경·영토 초기화
- 초기화 시 문제은행 보존

## GitHub와 온라인 서버

이 저장소는 게임 소스를 보관합니다. `docs/index.html`은 운영 중인 온라인 게임으로 연결되는 GitHub Pages 입구입니다.

게임의 `/api/game`과 데이터베이스는 Cloudflare Workers/D1 기반 서버에서 실행됩니다. GitHub Pages는 정적 파일만 제공하므로 서버 저장 기능 자체를 실행하지 않습니다. 현재 운영 서버를 그대로 이용하므로 기존 방·문제·점령 기록이 유지됩니다.

GitHub에 코드를 수정해서 올리는 것만으로 운영 서버가 자동 갱신되지는 않습니다. 게임 수정 후 별도로 서버에 빌드·배포해야 합니다.

## 개발

- Node.js 22.13 이상, pnpm 11.25
- React / TypeScript / Vinext / Vite
- Cloudflare Workers 및 D1 데이터베이스 (`DB` 바인딩)
- `app/page.tsx`: 교사·학생 화면
- `app/api/game/route.ts`: 권한 검사·문제 승인·점령·저장
- `questions.json`: 기본 200문항
- `drizzle/0000_hot_snowbird.sql`: 데이터베이스 스키마
- `tests/game-api.mjs`: 서버 로직 검사

```bash
pnpm install
pnpm dev
```

서버를 다른 계정에 배포하려면 D1 저장소 생성, 마이그레이션 적용, DB 바인딩과 호스팅 설정이 필요합니다. 현재 운영 데이터와 인증 토큰은 이 저장소에 포함하지 않습니다.

수도는 시대별로 달라지므로 각 나라를 대표하는 시작 지점을 선택했습니다. 가야는 금관가야의 김해를 사용합니다. 북방 확장 영역과 한강 유역은 학습용 근사 범위이며 특정 시대의 실제 국경이나 정밀 유역 경계를 나타내지 않습니다. 기존 방은 소유권과 문제를 보존하며 빈칸 300개를 추가하고, 새 방이나 영토 초기화 후에는 수도 근처에서 시작합니다. 문제의 공통 학습 주제는 출판사별 교과서 단원과 다를 수 있습니다.

## 실시간 현황판과 개인 기여도

- 오른쪽 현황판의 나라 순위: 점령 땅 수 + 한강 가중치 = 국력 총점. 한강 유역 1칸마다 +1점 추가. 동점은 공동 순위입니다.
- 개인 기여도: 이름·나라·현재 보유한 기여 영토·가중치·정답 풀이 수·승인된 출제 수를 표시합니다.
- 개인 점수는 현재 소유 영토 기준이며 재점령 시 점령자에게 이동합니다. 풀이·승인 출제 기록은 땅을 빼앗겨도 유지됩니다. 같은 땅의 반복 정답은 풀이 수에 중복 합산하지 않습니다.
- 퇴장해도 이번 게임의 기여 기록은 남습니다. 영토 초기화 시 개인 기여 기록도 초기화됩니다.
- 시작 영토와 기능 추가 전 점령은 개인에게 소급 배정하지 않습니다.
- 현황은 3초 간격으로 갱신되며 마지막 확인 시각과 연결 상태를 표시합니다.
- 첫 접속 시 안내 팝업을 표시합니다. 이후 상단 게임 안내에서 다시 열 수 있습니다.
- 울릉도·독도는 각각 1점의 미개척 영토로 추가되며 클릭하기 쉽도록 확대 표시했습니다.

## 게임 종료와 결과 기록

- 교사는 화면 위 `게임 종료`를 눌러 나라별 국력·개인 기여도·최종 영토 소유 현황을 서버에 저장합니다.
- 결과 저장과 활성 게임방 삭제는 한 번의 데이터베이스 트랜잭션으로 처리합니다. 저장 실패 시 방을 삭제하지 않습니다.
- 학생 화면도 자동으로 최종 결과로 전환되며, `방 나가기 · 메인으로`를 누르면 메인 화면의 게임 기록으로 돌아갑니다.
- 종료된 방은 재입장과 점수 변경이 차단됩니다. 중복 종료를 눌러도 동일 기록을 반환합니다.
- 메인 기록은 최종 나라 순위와 점수를 표시하고, 참여했던 기기의 저장된 접근 정보가 있으면 개인별 기여도·전체 영토·문제은행이 포함된 상세 결과를 확인하거나 JSON 파일로 내려받을 수 있습니다. 참여하지 않은 기기에는 나라별 요약만 표시합니다.
- 결과는 진행 중인 방과 별도인 D1 `game_archives` 테이블에 보관됩니다. 신규 배포 시 `drizzle/0001_silky_luckman.sql` 마이그레이션이 필요합니다.

## 시대별 방 설정
교사는 삼국시대·남북국시대·고려시대·조선시대·일제 강점기·대한민국 중 지도를 선택하고 팀 이름을 편집할 수 있습니다. 삼국·남북국은 도읍지 근처에서, 다른 시대는 교사가 지도에서 지정한 위치에서 시작합니다. 출제 범위를 별도로 정하며 선택 범위에서 기본 200문항을 배치합니다.

영토 재점령은 횟수 제한이 없습니다. 현재 소유 팀에 영토 점수와 한강 가중치가 반영되며, 개인의 중복 풀이 수는 추가 집계하지 않습니다.

## 범위별 문제은행과 OX
9개 범위마다 4지선다 180문항·OX 20문항, 총 1,800문항입니다. 교사가 여러 범위를 선택해도 기본 배치는 180:20의 총 200문항입니다. 교사실에서 전체 문항과 정답·해설 JSON을 저장할 수 있습니다. 추가 승인 문제는 기본 문항에 더해집니다. 제작 근거와 교육과정 연계는 [검토 기록](data/QUESTION_BANK_REVIEW.md)을 참고하세요.
